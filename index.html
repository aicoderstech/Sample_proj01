Questions

How realistic is the fit?

Mirrorfit tracks 33 body landmarks and warps the garment photo onto your shoulders, arms and hips, with physics for the hem. It is a 2D fit, not a 3D simulation, so it gives a quick, convincing sense of colour, length and proportion rather than an exact size recommendation.

Is my camera video uploaded anywhere?

No. Body tracking runs entirely in your browser using WebAssembly. Only garment images you load from other websites pass through our image proxy, and only when the shop blocks direct access.

Which garment images work best?

Front-facing product photos of a single item on a plain white or light background, or PNGs with a transparent background. Tops, jackets, dresses and skirts work best.

Does it work on phones?

Yes. It works in current versions of Chrome, Safari, Edge and Firefox on desktop and mobile, as long as the page is served over HTTPS.

Can I host it myself?

Yes. Run npm run build and npm start, or deploy the dist/ folder to any static host (the image proxy needs the Node server).
